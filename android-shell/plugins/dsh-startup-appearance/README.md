# 启动动画

标准 Host settings namespace 与 `settings.plugin.item` 均为 `startup-appearance`；唯一设置为 `enabled`（默认开启），在“设置 → 插件 → 可配置插件”显示，不向设置左侧插入独立分类。

Android 桥只缓存 Host 配置供引擎初始化前使用。配置就绪后同步；初始停用不播放、重复配置不创建重复播放器，Cordis 卸载撤销监听并禁用原生动画，重新安装按保留的 Host 配置恢复。短暂断线不清掉已保存值。APK 对用户已删除的包/装配不自动重插，用户改过的包不覆盖。

关闭后恢复原有原生引导与网页加载 UI。启用时原生加载层覆盖默认网页 boot logo，检测到会话或侧栏挂载且 WebView 提交绘制后撤下；最多等待20秒，随后显露网页本身的错误/诊断，不用视频掩盖失败。不会等待视频播放完毕才进入聊天。

播放器、匹配首尾帧的静音循环、横竖屏、原始视频及回退首帧说明见 `../../docs/AGENTS/startup-screen.md`。`npm test` 检查设置同步、初始停用、启停重启、断线、卸载和重新接入；本机实测证据不提交。
