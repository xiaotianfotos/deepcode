# 小米遥控器

标准 Cordis 插件，Host namespace 与配置卡片 key 均为 `xiaomi-remote`。入口：设置 → 插件 → 可配置插件 → 小米遥控器。默认关闭；用户可启停、选择外接设备、通过按键录入修改三个按键及其动作。关闭与卸载撤销租约，不修改会话、草稿或系统键位。

默认映射适配发出 F5 / Back / Enter 的小米蓝牙语音遥控器：

| 按键 | Android 键码 | 默认动作 |
| --- | --- | --- |
| 语音 | 135 (F5) | 开始 / 结束语音输入 |
| 返回 | 4 (Back) | 退格删除，可长按 |
| 确认 | 66 (Enter) | 发送当前草稿 |

语音动作调用当前聊天/当前激活泳道的现有 ASR 按钮；转录进入草稿，再按确认发送。桌面语音在用户按键开启后，VAD 静音 5 秒自动转录并发送，再按语音键可提前结束；桌面忽略删除/确认动作，不编辑或提交隐藏草稿，前台聊天映射保持原样。无需 GPT Live，支持 DSH / Codex 等后端；使用当前配置的麦克风与语音服务，不表示已经接入遥控器内置麦克风音频。

默认只匹配外接、非虚拟且名称包含“遥控”或“remote”的设备；显式设备选择使用 Android descriptor，不持久化动态 deviceId。音量、方向、电源、主页、应用切换与系统专用助手键不接管。设置页点击“重新录入”后提示用户按对应键，原生捕获真实外接遥控器事件并保存，不要求手填键码。录入最长 15 秒，可取消；切走页面、失去焦点、停用或卸载会终止，迟到事件不会保存。录入的按下、长按重复及释放不触发原来的聊天操作，也不会使返回键退出设置或 F5 刷新网页。系统保留键不拦截并提示换键，重复映射提示冲突，旧壳无录入接口时按钮不可用。每个录入按钮上方只读显示已保存的按键名称与键码，重新录入保存后即时更新；取消或超时仍显示原绑定。折叠的检测说明保留最近按键用于排障。系统拦截的按键不会出现在应用事件中；不能承诺所有厂商语音键通用。

聊天仅在页面有焦点、编辑器可见且没有设置/模态对话框时获得短期原生租约；暂停、导航、卸载释放。依赖标准 `deckInput` 适配器，缺失时撤销输入；ASR 可选，关闭不影响删除/发送。重复按下语音/确认只触发一次，删除使用真实系统长按重复。断开的设备重连时 deviceId 改变不会沿用按下状态。

桌面展开面板后主动收起，会将按键焦点交给小球；遥控器启用、语音服务有效且 DeepCode 不在前台时，收起的小球也处理已绑定按键。小球窗口不弹输入法；触摸其他应用失去焦点后不会主动抢回，重新展开/收起恢复接管。关闭遥控器或语音服务、进入 DeepCode 前台会解除小球键盘焦点。仍属于窗口输入，不是全局监听；未使用辅助功能、root、ADB 全局注入或系统键位修改。

构建 `npm ci && npm run build`，契约检查 `npm test`。安卓由 `stage-xiaomi-remote.py` 和带 SHA 守卫的首次安装装配；已移除的插件不被 APK 升级自动插回。

配置 UI 的样式限定在 `.dsh-remote`，随卡片挂载，使用主题色与容器宽度换行，不依赖其他插件加载 CSS。维持标准插件槽位，不新增左侧设置栏目。
