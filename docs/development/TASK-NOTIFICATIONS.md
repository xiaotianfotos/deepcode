# 任务通知与桌面语音分流

`dsh-task-notifications` 提供标准 `task-notifications` settings namespace 与同 key 的插件卡片。默认启用，可关闭全部任务通知或后台进度；不修改系统通知授权，也不停止 Agent。引擎前台服务的必要常驻通知独立保留。既有悬浮球默认关闭及用户已保存的启用偏好不变。

Host 将设置原子写入应用私有 `.task-notifications.json`，原生通知观察器读缓存，页面暂停不影响任务投递。`NotifyStore` 统一持有该目录的 FileObserver，悬浮球只订阅/退订监听回调，禁止再创建同目录观察器，以免共享 inotify watch 被覆盖或停止。卸载 Host 写入停用配置，原生撤下本插件管理的通知。缺失缓存兼容历史通知行为，损坏配置关闭任务通知。多个会话的进度使用不同稳定 ID，结束撤进度并更新结果；没有可量化进度时只显示正在处理，不编造百分比。状态事件不包含流式 token、工具参数或推理内容。

客户端只报告当前视口内的会话身份（包括可见工作台泳道）；与 ASR 开关无关。原生再核对 Activity 前台、屏幕亮起和解锁。正在查看的会话只保留静默通知，不重复横幅；其他会话仍正常提醒。审批和提问保留原生操作入口，不因前台状态丢弃。

桌面语音当前会话仅在最近 2.5 秒成功取得回复流且设备可交互时，将成功完成通知降为静默记录；错误、阻塞、审批与提问继续提醒。失败或停用立即清除该租约；息屏不以不可见浮层吞掉提醒。TTS 仍仅由显式 say 触发，不自动朗读全部回复。

桌面顶部浮层仅在语音成功提交后显示胶囊等待态，按请求 ID 绑定实际回合，首段正文到达后展开文字框，保留至最后正文更新后 60 秒；工具阶段保留最近正文，普通文字任务不触发顶部浮层。点按打开该会话完整聊天。收音时绿色音量填充，识别/发送/等待回复为蓝色边环。关闭浮层不关闭任务通知。

不依赖小米超级岛审核、无障碍或额外 ADB 授权。Android Live Updates 与厂商超级岛暂未接入，不宣称普通通知拥有该展示形态。

验证入口：插件 `npm test`、原生 `TaskNoticePolicyTest` 和通知契约测试；设备检查并发会话、前后台、锁屏、关闭/重开、卸载/重装与重复提醒。测试生成的记录和截图放根 `.local/validation/`，结束后 HOME、SLEEP 并确认 OFF。
