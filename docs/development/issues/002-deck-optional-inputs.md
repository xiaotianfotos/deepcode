# P02：工作台可选语音与手柄

## 问题与交付

工作台包的 `dsh.client.inject` 和客户端 `inject` 同时硬依赖语音、手柄。用户卸载任一输入插件时，Cordis 会连带卸载工作台。将两种输入改为可选集成，保持标准聊天组件、文字输入、附件和四泳道身份独立存活。

本任务仅修改 `android-shell/plugins/dsh-client-ui-voice-deck/` 内的源码、测试、README 和包的客户端依赖声明。不得改变依赖版本或锁文件、原生桥、其他插件、响应式布局、折叠效果、打包脚本或账号配置。统一设置迁移属于后续 P03–P05。

## 行为要求

1. 语音和手柄均不存在时，工作台仍可启用；会话选择、触屏横滑、草稿、附件与文字发送正常。
2. 只有语音或只有手柄时，各自独立工作。缺少语音时录音操作给出明确提示，文字发送不被不存在的语音阻断。
3. 使用固定 DSH/Cordis 运行时支持的可选服务生命周期；同时解除包级和服务级硬依赖。不能仅使用可选链，也不能用轮询探测服务。
4. 输入提供方卸载、重载、替换时，释放旧手柄绑定和重复按键状态，不向已卸载的语音服务调用。恢复后只绑定一次，不重挂整个工作台，不重新注册泳道视图，不重复获取 stage 租约。
5. 工作台关闭、视图退出、插件卸载后无手柄 sink 或新增监听泄漏；迟到回调不得继续操作草稿。保留语音现有归属与 held 文本机制，不转投其他会话，不清除录音恢复数据。
6. 保持每屏两列、横滑惯性、正文选字、附件和转录原会话归属、仅外接键盘自动聚焦末尾，以及 Fold 右半画布交接。不能停止后台 Agent。

## 验证

- 覆盖两插件均缺失、分别存在、均存在四种组合。
- 覆盖工作台挂载时输入服务到达、卸载、替换、重新到达，以及工作台关闭后的迟到事件；验证绑定和清理次数、同一工作台服务/视图身份、四槽与 active 不变。
- 测试应执行实际集成代码。若使用模拟 DOM/服务，明确模拟范围；至少对实际固定 Cordis 服务生命周期进行独立验证，不能只检查源码字符串或自行实现一个“Cordis”替身。
- 保留现有 state、惯性与选字测试；运行 TypeScript 检查、esbuild 和全部包测试，执行 `git diff --check`。
- 原生硬件按键和实际麦克风不属于本地模拟覆盖；本地通过后在平板补验。Fold 专属验收另行授权。
